# Ecos del Abismo — v0.2

Prototipo web de RPG de fantasía oscura, vista superior 2D, combate en tiempo real y equipo de hasta tres personajes.

## Contenido de esta versión
- Mapa explorable de mazmorra con muros y habitaciones.
- Colisiones para evitar atravesar paredes.
- Enemigos que persiguen y atacan al jugador.
- Ataque básico y habilidad mágica con coste de maná.
- Poción de curación.
- Experiencia, subida de nivel y atributos.
- Cofre con recompensa.
- Puerta que se abre al derrotar a los enemigos de la sala.
- Reclutamiento progresivo de Lyra y Brom.
- Jefes cada tres mazmorras, con estadísticas crecientes.
- Controles táctiles, teclado y diseño responsive.

## Ejecutar
Abre `index.html` en un navegador moderno o publica los tres archivos web en GitHub Pages.

## Actualizar el repositorio sin perder la publicación
1. Descarga la versión anterior del repositorio como ZIP o conserva una copia de sus archivos.
2. En `Dancreative2/ecos-del-abismo`, abre cada archivo existente y utiliza Edit (icono de lápiz) para reemplazar su contenido:
   - `index.html` con el nuevo `index.html`
   - `style.css` con el nuevo `style.css`
   - `game.js` con el nuevo `game.js`
3. Guarda cada cambio con Commit changes en la rama `main`.
4. No cambies el nombre del repositorio ni la configuración de GitHub Pages.
5. Espera a que Pages termine el despliegue y recarga el sitio. Si ves la versión antigua, recarga la página o borra la caché del navegador.

Los commits de GitHub conservan el historial; puedes recuperar el contenido anterior desde el historial de cada archivo.

## Límites conocidos
Es una versión de prototipo. El estado del personaje no se guarda entre recargas; la progresión y las mecánicas de aliados están simplificadas. No hay cuentas ni multijugador en línea. El mapa usa arte procedural temporal y aún necesita sprites originales, audio y pruebas de balance.
